## ข้อกำหนดเอกสารที่ต้องรักษา

- เขียนภาษาไทยและให้ผู้อ่านเข้าใจโครงการได้ด้วยตัวเอง
- ห้ามกล่าวถึงโปรเจคเดิมหรือโปรเจคจบใน Proposal หากใช้ข้อมูลให้ระบุเป็นข้อมูลของโครงการโดยตรง
- ไม่มีแบบฟอร์มหรือหัวข้อบังคับจากสถานประกอบการ
- เป้าหมายคือทำระบบให้มีงาน Machine Learning ชัดเจนขึ้น
- เก็บเฉพาะหัวข้อหมายเลขเดิม 1, 2, 3, 4, 5, 8, 9 ตามคำขอผู้ใช้
- หัวข้อที่เก็บคือ ชื่อโครงการ, หลักการและเหตุผล, วัตถุประสงค์, ขอบเขตโครงการ, แนวทางพัฒนาโมเดล, แผนดำเนินงาน, ผลที่คาดว่าจะได้รับ
- ตัดหัวข้อ 6, 7, 10, 11 ออกแล้ว ลิงก์อ้างอิงโมเดลอยู่ในข้อ 5
- ยังไม่ได้สรุปโมเดลสุดท้าย จำนวนผู้ทดลองใช้ หรือรายการ input ทั้งหมด
- ระยะเวลาโครงการยืนยันแล้ว: 3 เดือน โดยศึกษาความต้องการและกำหนดขอบเขตระบบใน 1 เดือนครึ่งแรก ผู้ใช้ระบุว่าเพิ่งเริ่มทำงานพัฒนาและเหลือเวลาอีกประมาณ 40-45 วัน ข้อ 8 ปรับแผนแล้ว ให้เก็บคะแนน เตรียมข้อมูล และเตรียมหน้าจอควบคู่กัน ก่อนทดลองสองแนวทาง เลือกหนึ่งแนวทาง เชื่อมระบบ และประเมินผล ห้ามอ้างว่ากิจกรรมช่วงที่ผ่านมาเสร็จแล้วโดยไม่มีข้อมูลยืนยัน
- คำสั่งล่าสุด: ต้องทดลองฝึกทั้ง KNN Classification ของ scikit-learn และแนวทาง Surprise ก่อน แล้วเลือกเพียงหนึ่งแนวทางเป็นโมเดลหลักตามผลประเมิน โดยใช้ตัวชี้วัดการจัดลำดับเดียวกัน ไม่เปรียบเทียบ Accuracy กับ RMSE โดยตรง

## ข้อมูลที่ตรวจสอบแล้ว

- `dataset\attractions.json` มีสถานที่ 2,994 รายการ
- ครอบคลุมภาคเหนือและภาคใต้ รวม 31 จังหวัด ไม่ใช่ข้อมูลครบทุกภูมิภาค
- มีชื่อ คำอธิบาย พื้นที่ หมวดหมู่ ประเภท กิจกรรม ที่ตั้ง พิกัด และข้อมูลสื่อในบางรายการ
- ขณะนี้ไม่มีข้อมูลความชอบ คะแนน หรือประวัติการเที่ยวของผู้ใช้สำหรับฝึกโมเดล
- อายุและข้อมูลผู้ใช้อื่นยังเป็น input ที่อาจเพิ่ม ต้องยืนยันภายหลัง
- ไม่อ้างว่าอายุทำนายความชอบได้โดยไม่มีผลทดลองรองรับ

## แนวทางที่อาจารย์แนะนำ

1. https://surpriselib.com/
2. https://scikit-learn.org/stable/auto_examples/neighbors/plot_classification.html

อ่านเอกสารต้นทางแล้วและปรับ Proposal ให้สอดคล้อง:

- Surprise เป็นไลบรารีสำหรับระบบแนะนำจากคะแนนที่ผู้ใช้ระบุโดยตรง มีโมเดล เช่น SVD และ KNNBasic
- ข้อมูลสำหรับ Surprise คือรหัสผู้ใช้ รหัสสถานที่ และคะแนน ข้อมูลสถานที่อย่างเดียวไม่เพียงพอ
- Surprise มาตรฐานไม่ได้รับอายุหรือข้อมูลเนื้อหาสถานที่เป็นคุณลักษณะเพิ่มเติมโดยตรง
- ลิงก์ scikit-learn เป็นตัวอย่าง KNeighborsClassifier บนข้อมูลดอกไอริส เป็นงานจำแนกกลุ่ม ไม่ใช่ระบบแนะนำสำเร็จรูป
- Proposal เสนอประยุกต์ KNN Classification กับคุณลักษณะคู่ผู้ใช้-สถานที่และป้ายกำกับความสนใจจากคะแนนจริง
- เสนอเก็บคะแนนความสนใจ 1-5 จากผู้ทดลองใช้ก่อนฝึกโมเดล ยังไม่ยืนยันจำนวนผู้ทดลองใช้
- ไม่ใช้คะแนนสมมติหรือคะแนนที่สร้างจากกฎเป็นหลักฐานว่าระบบเรียนรู้ความชอบจริง
- มีวิธีแนะนำจากเนื้อหาเป็นตัวตั้งต้นสำหรับผู้ใช้ใหม่หรือกรณีคะแนนไม่เพียงพอ
- การทดลองแยกผู้ใช้ที่มีประวัติคะแนนกับผู้ใช้ใหม่ และหลีกเลี่ยงคู่ผู้ใช้-สถานที่ซ้ำข้ามชุดฝึกและทดสอบ
- ข้อ 5 มีแนวทางประเมิน MAE/RMSE สำหรับทำนายคะแนน, Precision/F1 สำหรับจำแนก และ Precision@K/NDCG@K สำหรับรายการแนะนำ
- ตัดตัวเลือก Logistic Regression, Random Forest และ Gradient Boosting จากร่างแล้ว
