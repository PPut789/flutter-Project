PROJECT CONTEXT FOR CLAUDE
TravelRecommendation / Flutter + Firebase + FastAPI KNN

โปรเจกต์นี้คืออะไร
====================

TravelRecommendation เป็นโปรเจกต์โครงงานระบบแนะนำสถานที่ท่องเที่ยวในประเทศไทย
โดยมี 3 ส่วนหลัก:

1. Mobile App
   - สร้างด้วย Flutter / Dart
   - ผู้ใช้สมัครสมาชิกหรือเข้าสู่ระบบ
   - เลือก preference เช่น ภาค จังหวัด หมวดหมู่ ประเภทสถานที่ และกิจกรรม
   - แอปแสดงสถานที่แนะนำจาก Firestore
   - มีหน้า detail, history, video feed, upload video, profile, settings

2. Recommendation Backend
   - สร้างด้วย FastAPI / Python
   - โหลดโมเดล KNN จากไฟล์ .pkl
   - ใช้แนวคิด Content-Based Recommendation
   - ใช้ One-hot + TF-IDF + weighted cosine similarity
   - Flutter สามารถเรียก backend เพื่อจัดอันดับสถานที่แนะนำ
   - ถ้า backend ใช้งานไม่ได้ Flutter มี local fallback scoring

3. Firebase
   - Firebase Auth ใช้จัดการ login/register
   - Cloud Firestore เก็บข้อมูลสถานที่, users, history, videos
   - Firebase Storage เก็บรูปสถานที่, รูปโปรไฟล์, วิดีโอ user-uploaded
   - รูปภาพ/วิดีโอในแอปไม่ได้ฝังใน APK เป็นหลัก แต่โหลดจาก Firebase Storage URL

Backend / KNN
=============

backend/main.py
---------------
FastAPI backend สำหรับ recommendation
- โหลด backend/models/travel_recommendation_knn_model_v2.pkl
- มี endpoint GET /health
- มี endpoint POST /recommend
- สร้าง user vector จาก preference
- ใช้ model_with_province ถ้าผู้ใช้เลือกจังหวัด
- ใช้ model_without_province ถ้าไม่เลือกจังหวัด
- ใช้ kneighbors() เพื่อหาอันดับสถานที่คล้ายที่สุด
- ส่งผลกลับให้ Flutter เอาไปจับคู่กับข้อมูลปัจจุบันใน Firestore

backend/requirements.txt
------------------------

backend/README.md
-----------------
เอกสารวิธีรัน backend และอธิบาย KNN artifact
ควรอ่านไฟล์นี้ก่อนแตะ backend

backend/models/travel_recommendation_knn_model_v2.pkl
------------------------------------------------------
โมเดล KNN เวอร์ชันปัจจุบัน
- Content-Based KNN
- One-hot: region, province, category, type
- Multi-label: activity
- TF-IDF: nameTh, nameEn, description, highlight, tags
- Weight โดยประมาณ:
  - region 2.0
  - province 2.5
  - category 3.0
  - type 3.0
  - activity 4.0
  - text 1.4

------------------------------------------------------
